# WeQ Remote 1.1.0

iOS 与 Android 源码版本均为 1.1.0，iOS build 16，Android versionCode 12。当前版本尚未发布。

## 主要变化

- 首页的「连接」先连电脑并使用当前网页版本；有网页缓存时可单独进入，不自动连电脑。连接失败不会删掉本机缓存。
- 连接菜单提供「重新连接」和默认开启的「启动 App 时自动连接」，软件更新放在最后。
- 首屏加载按实际资源进度展示；错误界面的「重新加载」只重载当前网页，不强制重新连接。
- 两端可直取受支持的 QQ 图片，并以二进制交给网页。iOS 按变更增量保存跨入口的目录和消息缓存。

完整变更见 [更新记录](../../CHANGELOG.md#110---未发布)。
