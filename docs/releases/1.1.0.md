# WeQ Remote 1.1.0

iOS 与 Android 源码版本均为 1.1.0，iOS build 14，Android versionCode 12。当前版本尚未发布。

## 主要变化

- 已缓存的聊天页可在冷启动时直接打开，选路、授权和同步在后台进行。暂时掉线时仍可浏览缓存的会话、消息和头像。
- 点击「重新加载」会立即向电脑检查网页更新，新分包准备齐全后切换。检查失败时保留已打开的聊天页。
- 首屏加载按实际资源进度展示。连接页区分电脑连接、授权和网页启动失败，网页失败时可沿用原配对重试。
- 两端可直取受支持的 QQ 图片，并以二进制交给网页。iOS 按变更增量保存跨入口的目录和消息缓存。

完整变更见 [更新记录](../../CHANGELOG.md#110---未发布)。
