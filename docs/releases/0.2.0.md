# WeQ Remote 0.2.0

iOS build 7，Android versionCode 5。

- 支持 v4 多入口配对码，错峰探测局域网与 WeQ 专用 Tailscale，兼容 v1–v3。iOS 等待批准时遇到临时超时可保留申请并换路。
- 首页突出扫码与配对链接。前后台切换保留网页，短暂断网在原页重试，撤销授权清除手机凭据。
- 支持文件选择、媒体授权、外链、文件保存及网页截图。Android 使用系统保存位置，iOS 使用系统分享菜单。
- 两端加入 WeQ 图标。iOS 修复动态名片背景自动全屏播放。

附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
