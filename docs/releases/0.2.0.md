# WeQ Remote 0.2.0

iOS 与 Android 统一使用 0.2.0，沿用当前源码构建号：iOS build 7、Android versionCode 5。

## 内容

- 支持 v4 多入口配对码，保存局域网与 WeQ 专用 Tailscale 入口，错峰探测并选择可用路径；继续兼容 v1/v2/v3 邀请。
- iOS 等待电脑批准时遇到临时超时会保留本次配对并重试，可切换入口继续查询批准结果。
- 调整原生连接页，突出扫码与配对链接；前后台切换保留已连接网页，短暂断网在原页面重试，撤销授权仍清除凭据。
- 两端加入 WeQ 应用图标，支持 iOS 深色外观与 Android 自适应图标。
- 补齐网页文件选择、媒体授权、外链、文件保存及当前网页截图；Android 使用系统保存位置，iOS 使用系统分享菜单。
- 修复 iOS 动态名片背景自动弹出全屏播放器的问题，背景保持页内播放。

## 安装包

- `weq-remote-0.2.0-ios-arm64-unsigned.ipa`：iOS 17 起，仅真机 arm64，未签名。安装前需对 App、内嵌 Framework 和 entitlements 正确签名。
- `weq-remote-0.2.0-android-arm64.apk`：Android 8.0 / API 26 起，仅 arm64-v8a，使用本轮 runner 的临时开发签名；与既有安装证书不同时不能直接覆盖安装，请保留既有应用及数据。
- `ios-build.json` 与 `android-build.json`：来源提交、版本、工具链与产物摘要。
- `SHA256SUMS`：上述附件的 SHA-256 校验和。

手机端继续连接电脑 WeQ，由电脑提供业务页面与授权。新版原生能力需要更新手机安装包；仅更新电脑网页不会更新已安装的手机壳。

本次自动化验证覆盖协议测试、原生构建、打包和发布。网页上传、录音、通话、下载、摄像头扫码、蜂窝切网与长期耗电尚未完成真实手机验收；不包含手机屏幕共享、原生推送或后台持续通话，未上架应用商店。
