# WeQ Remote 1.0.0b2

源码版本：iOS / Android 1.0.0b2，iOS build 10、Android versionCode 8。iOS 系统版本为 1.0.0，应用内通过 `WeQReleaseVersion` 显示完整 Beta 版本。

## 更新

- 连接中主按钮显示「停止」，空闲时显示「连接」；停止后暂停自动重试。
- 已保存电脑的连接按钮左侧新增扫码入口，可更新地址与 Tailscale Key，复用原设备令牌验证，不重新申请电脑授权。
- 新地址验证成功后才保存；带新 Key 的更新先完成入网。日常选路保持错峰竞速，首个可用入口胜出。
- 延续 1.0.0b1 的全屏网页、连接菜单、三段式连接首页、启动阶段显示与恢复连接修复。
- 连接圆环显示首屏代码资源的加载比例、已加载／总大小与资源项数；缓存命中同样计入已加载量，下载完成后继续等待界面就绪。
- iOS 持久保存网页数据，Android 持久缓存完整代码资源并流式转发响应，跨重启复用缓存；Android HTTPS 连接优先协商 HTTP/2。
- Android 为已授权电脑保留固定的本地网页来源，重连、切换路径与重启后继续复用网页存储；修复网页代理关闭时的竞态。

## 安装包

- Android：arm64 APK，Android 8.0 起，使用本轮构建的临时开发签名；与已有安装签名不同时不能直接覆盖安装。
- iOS：真机 arm64 未签名 IPA，iOS 17 起，安装前需要自行正确签名 App 与内嵌 Framework。
- 两端构建来源记录与 `SHA256SUMS` 随安装包附上。

资源进度与启动阶段需要同步更新电脑上的 WeQ；会话及联系人缓存由电脑提供的 Web 页面维护。原生连接与界面变化需要更新手机安装包。本版本未上架应用商店，实际网络与设备交互验收不以自动化构建通过代替。
