# WeQ Remote 1.0.0b2

iOS 系统版本 1.0.0（build 10），Android versionCode 8，两端应用内显示 1.0.0b2。

- 可停止连接，或为已配对电脑重新扫码更新地址与 Tailscale Key。新入口通过原设备令牌验证后保存。
- 圆环显示首屏代码加载比例、大小与项数，缓存命中计入加载。资源完成后继续显示网页启动阶段。
- iOS 持久保存网页数据。Android 固定同一授权的本地网页来源，支持持久代码缓存、流式转发与 HTTP/2，并修复代理关闭竞态。
- 首页可在键盘弹出、横屏或内容过高时滚动。iOS 改进字号与按钮点击区域。Android 修复 8–10 的安全区兼容。

资源进度需配套新版电脑 WeQ。附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
