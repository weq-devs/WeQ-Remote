# WeQ Remote 0.1.0

独立仓库首次 GitHub 发布。iOS build 6，Android versionCode 4。此前的 0.3.x 为未发布的开发版本。

- 原生扫码、粘贴配对链接、电脑端批准与自动重连。
- 支持局域网 HTTPS 指纹校验与内嵌 Tailscale。Keychain／Keystore 保存设备凭据。
- 原生 WebView 加载电脑提供的 WeQ 网页。APK／IPA 由独立仓库的 CI 构建。

新应用标识为 `io.github.weqdevs.remote`。旧标识的安装需单独保留，新应用安装后重新配对。附件包含 Android 8.0 起的 arm64 APK、iOS 17 起的 arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
