# WeQ Remote 0.1.0

WeQ Remote 独立仓库首次 GitHub 发布。iOS 与 Android 统一使用 0.1.0，此前 0.3.x 是未发布的开发版本，不是本次降级安装包。内部构建号继续递增：iOS build 6、Android versionCode 4。

## 内容

- 原生扫码 / 粘贴邀请、电脑端配对批准与自动重连。
- 局域网 HTTPS 证书指纹校验，以及内嵌 Tailscale 连接。
- Keychain / Android Keystore 保护设备凭据，原生 WebView 复用电脑提供的 WeQ Web。
- 独立手机源码仓库和 CI、IPA / APK 自动化构建与发布。

## 安装包

- `weq-remote-0.1.0-ios-arm64-unsigned.ipa`：iOS 17 起，仅真机 arm64，**未签名**。需自行对 App、内嵌 Framework 和 entitlements 正确签名后安装；不能直接安装到普通 iPhone。
- `weq-remote-0.1.0-android-arm64.apk`：Android 8.0 / API 26 起，仅 arm64-v8a，使用本轮 runner 的临时开发签名。不能保证覆盖其他轮次或本机证书签名的既有安装，不是商店正式签名。
- `ios-build.json`：iOS 来源提交、依赖、工具链和原始 IPA 摘要。
- `android-build.json`：APK 实际包身份、版本、来源提交和摘要。
- `SHA256SUMS`：上述附件的 SHA-256 校验和。

应用命名空间为 `io.github.weqdevs.remote`。旧身份安装不能原位升级或直接读取旧凭据，需要重新配对；本次发布不删除、迁移或重置任何设备数据。请保留既有安装和数据，不为安装本包先行卸载应用。

手机端仍需连接兼容的电脑 WeQ，业务页面与授权由电脑端提供。本次自动化检查覆盖 CI、原生编译、打包及上传，不代表真实手机摄像头、蜂窝切网、长期耗电或商店上架已验收。历史模拟器网络回执不等同于本次发布包的真机验收。
