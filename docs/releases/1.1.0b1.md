# WeQ Remote 1.1.0 Beta 1

两端应用内显示 1.1.0b1。iOS 系统版本为 1.1.0（build 19），Android versionCode 为 13。

- **连接**打开电脑当前网页版本。新版电脑先确认账号，再加载完整网页。可在首页直接打开本机缓存，连接失败时保留缓存。
- **连接菜单**可重新连接、断开及设置启动时自动连接。错误页的「重新加载」只重载当前页面。已经进入网页后掉线，仍可浏览缓存内容。
- **本机缓存**可查看用量、调整上限和清除业务数据。默认 256 MiB，目录、消息历史和媒体共用此空间，网页代码有独立缓存。
- **主题色**提供 9 个 WeQ 预设，默认亮蓝并跟随电脑。关闭同步后，手机使用自己的颜色。
- **网页加载**期间，首页保留资源进度直到页面就绪。前台加载与后台离线包共用哈希分包，正式网页构建变化时在后台准备新版。两端可向网页直接交付受支持的 QQ 图片字节。iOS 增量保存目录和近期消息，Android 合并进度绘制并将代码缓存写盘移到后台。

更新手机 App 后，配套升级电脑 WeQ 可使用轻量账号入口、主题色同步、业务缓存及图片直取。旧电脑可继续连接。

附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android APK 使用 CI 调试签名，覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
