# WeQ Remote 1.0.1

版本：iOS / Android 1.0.1，iOS build 13、Android versionCode 11。iOS 系统版本与应用内版本均为 1.0.1。

## 主要变化

- 启动页区分资源加载、已确认下载、缓存复用与来源待确认，不再把完整清单或手机内部缓存读取算成本次下载量。
- 首屏资源全部复用缓存时，只显示缓存已复用及后续实际初始化阶段；恢复检查等标题不再被后到的资源回执覆盖。
- Android 配合新版电脑网页完成首屏资源的一次自动重试；仍失败时回到连接页，不重载已就绪页面或重发业务操作。iOS 沿用现有启动桥，无需为网页重试另加原生流程。

## 发布产物

- iOS：本轮构建真机 arm64 未签名 IPA，iOS 17 起，安装前需对 App 与内嵌 Framework 正确签名。
- Android：arm64 APK，Android 8.0 / API 26 起。使用本轮临时开发签名，签名不同时不能直接覆盖已有安装。
- 两端构建来源记录与汇总 SHA256SUMS。

业务网页仍由电脑上的 WeQ 提供。首屏资源重试需配套新版电脑网页；本轮未新增真实手机安装及运行验收，未上架应用商店。
