# WeQ Remote 1.0.0b3

源码版本：iOS / Android 1.0.0b3，iOS build 11、Android versionCode 9。iOS 系统版本为 1.0.0，应用内通过 `WeQReleaseVersion` 显示完整 Beta 版本。本版本为 GitHub 测试发布。

## 更新

- 统一连接首页与聊天内菜单的连接详情：当前电脑入口、系统网络／内嵌 Tailscale、Tailscale 状态、最近验证时间、请求耗时、App 与手机系统版本集中显示在「更多」，保留立即检查、重新加载和断开。
- 前台每 15 秒验证连接，失败后每 5 秒重试；连续两轮失败时提示「连接可能已中断，正在重试」，不销毁网页，成功后自动消除。后台停止轮询，撤销授权仍立即清理。
- 新增软件更新检查，探测加速源并限量取样测速，显示当前／最新版本与选中来源，提供下载和备用源。「检查测试版」默认关闭，开启后比较正式版与测试版，不提示降级。
- Android 在横竖屏、窗口和键盘形态变化时保留当前网页、连接及待完成的文件选择／下载；支持网页全屏，系统返回优先退出全屏。
- iOS 补齐网页提示、确认和输入的原生对话框；内嵌 Tailscale 的 HTTP 网页通过原生桥采集麦克风和摄像头，HTTPS 继续使用 WebKit 采集。
- 两端异步获取的外链通过本地接口交给系统打开，不覆盖聊天页面；同源文件与 Blob 下载保留原有鉴权下载流程。
- 延续 1.0.0b2 的全屏网页、停止连接、扫码更新已授权电脑、资源字节进度与跨重启代码缓存。

## 安装包

- Android：arm64 APK，Android 8.0 起，使用本轮构建的临时开发签名；与已有安装签名不同时不能直接覆盖安装。
- iOS：真机 arm64 未签名 IPA，iOS 17 起，安装前需要正确签名 App 与内嵌 Framework。
- 两端构建来源记录与 `SHA256SUMS` 随安装包附上。

网页采集桥与相关业务入口需要同步更新电脑上的 WeQ；原生变化需要更新手机安装包。更新下载由系统浏览器承接，不自动安装。本版本未上架应用商店；真实手机音视频、公共网络切换和后台持续通话未作为本次自动化发布验收项目。
