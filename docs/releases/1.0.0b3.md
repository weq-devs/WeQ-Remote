# WeQ Remote 1.0.0b3

iOS 系统版本 1.0.0（build 11），Android versionCode 9，两端应用内显示 1.0.0b3。

- 首页与网页连接菜单共用连接详情，可查看当前入口、网络、Tailscale、验证时间、耗时和版本，或立即检查、重新加载、断开。
- 前台每 15 秒验证连接，失败后每 5 秒重试。连续两次失败时提示并保留网页，恢复后清除提示。
- 软件更新支持下载源探测、有限取样测速和可选的测试版检查，下载由系统浏览器承接。
- Android 旋转和窗口变化时保留网页，并支持网页全屏。iOS 补齐网页对话框和 Tailscale HTTP 页面摄像头／麦克风采集。两端可将异步外链交给系统，同时保留同源鉴权下载。

HTTP 采集需配套新版电脑网页。附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
