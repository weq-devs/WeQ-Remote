# WeQ Remote 1.0.0

源码版本：iOS / Android 1.0.0，iOS build 12、Android versionCode 10。iOS 系统版本与应用内版本均为 1.0.0。本版本使用 GitHub 正式发布，不标记为 Pre-release。

## 更新

- 双端版本从 1.0.0b4 改为 1.0.0，移除 Beta 标识，构建号保持不变。
- iOS 向当前电脑提供的网页同步系统低数据与计费网络状态；Android 同步计费网络和 Data Saver 状态，切网与返回前台时更新，配合 WeQ 的应用级省流量设置。
- 省流量时更新检查仍核对版本与可用下载源，但不下载安装包取样测速；网页设置只作为当前连接的运行参数，不增加设备级覆盖。
- 保留 b4 的统一前台连接检测与 WeQ 断连／恢复横幅、设备型号及系统／客户端版本上报、iPadOS 窗口角部布局和可选的本机 SideStore 源发布入口。
- 保留扫码配对与多入口连接、连接详情、持久网页资源缓存、文件选择、媒体授权、外链与文件保存。聊天业务页面继续由电脑上的 WeQ 提供。

## 安装包

- Android：arm64 APK，Android 8.0 起，使用本轮构建的临时开发签名；与已有安装签名不同时不能直接覆盖安装。
- iOS：真机 arm64 未签名 IPA，iOS 17 起，安装前需要正确签名 App 与内嵌 Framework。
- 两端构建来源记录与 `SHA256SUMS` 随安装包附上。

省流量桥、连接横幅、设备详情和 iPadOS 布局需配套更新电脑上的 WeQ；原生变化需要更新手机安装包。更新下载由系统浏览器承接，不自动安装。本版本未上架应用商店。真实手机断网／恢复、iPad 窗口、音视频与 SideStore 自动刷新仍按对应平台单独验收，版本转为 1.0.0 不代表这些项目已完成实机验收。
