# WeQ Remote 1.0.0

1.0 正式版，沿用 b4 的 iOS build 12 和 Android versionCode 10。

- 手机向电脑提供的 WeQ 网页同步系统低数据、计费网络与 Android Data Saver 状态。切网及返回前台时刷新。
- 省流量模式下，软件更新仍检查版本和可用下载源，跳过安装包取样测速。

省流量桥需配套新版电脑 WeQ 与手机 App。附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
