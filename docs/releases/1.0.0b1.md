# WeQ Remote 1.0.0b1

1.0 首个 Beta，作为 GitHub Pre-release 分发。两端应用内均显示 1.0.0b1；Android versionName 为 1.0.0b1、versionCode 为 6。iOS 系统版本为 1.0.0、build 为 8，`WeQReleaseVersion` 保存完整 Beta 标识。

## 内容

- 原生连接首页采用三段式布局，底部集中扫码、配对链接、重新连接等操作，并显示网络状态和版本号；iOS 首页不再上下滚动。
- 连接时留在首页显示实际启动阶段，网页完成恢复检查、账号初始化和真实界面绘制后再全屏显示；会话及好友等业务列表在界面内异步加载。
- Android 提前订阅并补读网页启动状态，避免等待尾部图片等资源；修复初始化时返回前台重新打开网页的问题，并为脚本异常、代码资源下载失败提供具体提示。
- 全屏网页隐藏原生工具栏，连接菜单由网页调用，可重新加载或断开并保留电脑；首页删除电脑需要确认。
- Android 系统返回与 iOS 侧滑交给移动网页处理，Android 顶层返回不再断开连接。
- 恢复连接复用选路探测的鉴权状态，不再重复核验，也不另设更短的探测硬超时。

## 安装包

- `weq-remote-1.0.0b1-ios-arm64-unsigned.ipa`：iOS 17 起，仅真机 arm64，未签名；安装前需对 App、内嵌 Framework 和 entitlements 正确签名。
- `weq-remote-1.0.0b1-android-arm64.apk`：Android 8.0 / API 26 起，仅 arm64-v8a，使用本轮 runner 的临时开发签名；若与既有安装证书不同，不能直接覆盖安装，请保留既有应用及数据。
- `ios-build.json`、`android-build.json`：来源提交、版本、工具链与摘要；iOS 记录区分系统 `version` 和完整 `releaseVersion`。
- `SHA256SUMS`：上述附件的 SHA-256 校验和。

手机网页由电脑 WeQ 提供，启动阶段及连接菜单需配套新版电脑网页。此版本不是 App Store / TestFlight 或商店正式发布；真实手机的扫码、媒体、蜂窝切网与长期耗电验收状态沿用各平台文档，不因版本进入 1.0 Beta 而视为全部完成。
