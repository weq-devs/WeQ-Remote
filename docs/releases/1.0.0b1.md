# WeQ Remote 1.0.0b1

iOS 系统版本 1.0.0（build 8），Android versionCode 6，两端应用内显示 1.0.0b1。

- 三段式连接首页集中扫码、配对链接与重连，显示网络状态和版本。iOS 首页固定排版。
- 首页显示实际启动阶段，等界面完成绘制后进入全屏网页。Android 启动失败时提供资源和脚本诊断，前后台切换保留初始化中的网页。
- 网页连接菜单可重新加载或断开并保留电脑。首页删除电脑需要确认。系统返回与侧滑交给移动网页处理。
- 恢复连接复用选路取得的鉴权状态，并沿用正式请求的超时预算。

启动阶段及网页连接菜单需配套新版电脑 WeQ。附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
