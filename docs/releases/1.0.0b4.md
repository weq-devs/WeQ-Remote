# WeQ Remote 1.0.0b4

iOS 系统版本 1.0.0（build 12），Android versionCode 10，两端应用内显示 1.0.0b4。

- 两端统一前台断网检测。系统网络变化、网页同源请求失败与周期校验共同触发检查。后台暂停，鉴权验证成功后恢复。
- 断网和恢复通过同一条 WeQ 横幅更新。探测超时时保留网页和代理。
- 手机版随现有配对和状态请求上报型号、OS、客户端版本及构建号。已配对设备会自动补齐。
- iPadOS 26 支持将系统窗口角部占位同步给网页。提供可选的 iOS 本机 SideStore 源发布入口，原应用身份的自动刷新仍待验证。

横幅、设备详情及 iPad 布局需配套新版电脑 WeQ。附件包含 Android arm64 APK、iOS arm64 未签名 IPA、构建来源及 `SHA256SUMS`。Android 覆盖安装需相同签名。iOS 安装前须签名 App 与内嵌 Framework。
