# WeQ Remote 1.0.0b4

源码版本：iOS / Android 1.0.0b4，iOS build 12、Android versionCode 10。iOS 系统版本为 1.0.0，应用内通过 `WeQReleaseVersion` 显示完整 Beta 版本。本版本为 GitHub 测试发布。

## 更新

- 统一 iOS 与 Android 的前台连接检测：正常每 15 秒验证，首轮总预算 5 秒，第二轮 10 秒，之后每轮增加 5 秒，成功后重置。入网与全部备用入口共用预算，失败重试至少间隔 500 毫秒。
- 断连提醒独立于探测等待：第二轮开始后 5 秒、无网络或网页失败持续 10 秒、前台 30 秒没有成功验证时触发。系统网络变化和同源 fetch／WebSocket 失败合并检查，主动取消、正常关闭及外部来源失败不触发。后台停止监听和计时，网络恢复后须实际鉴权验证成功才判定恢复。
- 断连与恢复统一通过共用网页的 WeQ 横幅原地更新，不再增加原生顶部条。断连提示保留到恢复或手动关闭，探测超时不销毁现有网页或代理。
- 两端随现有配对和状态请求上报设备型号、系统版本、Remote 版本与构建号，供电脑「已配对设备」详情展示；已有授权自动补齐，不需重新配对，不增加心跳，旧电脑继续兼容。
- iOS 在 iPadOS 26 起向网页同步系统窗口角部占位，供顶部操作区避让；随窗口尺寸更新，存在占位时首屏显示前先同步并等待绘制，不重建 WebView。旧系统和 Android 保持原路径。
- 增加可选的 iOS 本机 SideStore 源发布入口，不影响 CI；保留原应用身份的自动刷新仍待兼容修补和真实设备验收。

## 安装包

- Android：arm64 APK，Android 8.0 起，使用本轮构建的临时开发签名；与已有安装签名不同时不能直接覆盖安装。
- iOS：真机 arm64 未签名 IPA，iOS 17 起，安装前需要正确签名 App 与内嵌 Framework。
- 两端构建来源记录与 `SHA256SUMS` 随安装包附上。

连接横幅、设备详情及 iPadOS 布局需配套更新电脑上的 WeQ；原生变化需要更新手机安装包。更新下载由系统浏览器承接，不自动安装。本版本未上架应用商店；自动化构建及离线回归不代表真实手机断网／恢复、iPad 窗口、音视频或 SideStore 自动刷新已经验收。
