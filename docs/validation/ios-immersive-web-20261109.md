# iOS 已连接网页全屏与操作入口

日期：2026-11-09（北京时间）。源码版本：0.2.0 开发版，未发布。

## 实现范围

- 已连接网页隐藏顶端原生导航栏，WKWebView 占满可用屏幕（状态栏与底部安全区仍按系统布局）。
- 原先顶端的重新加载、断开电脑、删除电脑收进右侧悬浮菜单，动作与确认行为不变；删除仍为破坏性样式。
- 连接异常提示条仍只在出错时出现，不常驻占用高度。
- Android 顶部工具栏保持原样，本轮不改。

## 验证

- 使用 iPhoneOS 17 SDK 对 iOS 源码做类型检查（TailscaleKit 与 WebContainer 用本机替身，仅验证语法与类型），通过。
- Swift 宿主机协议测试 21 项通过（与本次 UI 改动无直接关系，确认未破坏协议层）。
