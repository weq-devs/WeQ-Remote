# 恢复连接的重复核验清理验证

日期：2026-11-09（北京时间）。源码版本：0.2.0 开发版，本轮不改版本号、不发布。

## 改动范围

- iOS 与 Android 在恢复已配对连接时，不再先做一次只读探测、随后再请求一次 `/v1/status`：
  - 已配对设备（多入口）的选路探测本身就是一次鉴权状态读取，成功结果作为本次连接的校验直接沿用，不追加第二次状态请求；
  - 单入口恢复不预探测，直接由正式状态请求校验；
  - 尚未批准的设备和首次配对继续只用 `/v1/hello` 找可达路径，设备凭据不变。
- 恢复连接的探测不再使用 3 秒硬超时，改为正式请求的超时预算，避免 Tailscale 冷启动或弱网下把可用入口误判为不可达。
- 401 仍在选路阶段终止并清除手机凭据；局域网证书指纹不匹配仍在建连阶段终止，Android 给出「电脑证书已变化，请删除电脑后重新配对」，不静默降级。

涉及实现：iOS `RemoteModel` / `RemoteProtocol`，Android `MainActivity` / Go `routes`。
